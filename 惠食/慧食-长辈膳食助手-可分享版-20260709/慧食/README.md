# 慧食·长辈膳食助手 本机封闭试用版

慧食是一个可本地运行的长辈膳食辅助工具，包含健康档案、语音/文字记餐、饭菜照片分析、真实记录日历和本机家人视图。

## 产品边界

- 当前版本没有真实账号登录、家庭绑定、电话、消息推送或跨设备同步。
- 健康档案和已确认的餐食记录保存在当前浏览器的本地存储中，可在身份选择页清除。
- 只有用户主动发起语音、文字或照片分析时，对应输入和健康档案才会发送给当前配置的 AI 服务。
- 照片分析服务不可用或结果不明确时，系统不会按文件名、颜色或样例数据猜测食物。
- AI 结果不能降低本地过敏和慢病红线；所有建议仅供参考，不能替代医生诊断。
- 出现呼吸困难、喉咙发紧、嘴唇或舌头肿、意识异常或明显呛咳时，应立即停止进食并拨打 120。

## 运行

需要 Node.js 18 或更高版本。

Windows 可双击 `start.bat`，macOS 可双击 `start.command`。也可以手动启动：

```bash
npm start
```

默认地址：`http://127.0.0.1:8787/`。

如需更换端口：

```bash
PORT=8789 npm start
```

PowerShell：

```powershell
$env:PORT=8789; npm start
```

使用手机测试时，让电脑和手机连接同一 Wi-Fi，并通过电脑局域网 IP 访问。部分手机浏览器只有在 HTTPS 下才开放完整的麦克风能力；系统相册选择通常不需要摄像头权限。

## AI 配置

不要把真实密钥写进前端文件。根据 `.env.example` 在项目目录创建 `.env`，填写需要使用的服务密钥并重启服务。

主要接口：

- `/api/analyze-voice-meal`：语音转写后的文字餐食分析
- `/api/analyze-photo-meal`：饭菜照片识别和膳食分析
- `/api/analyze-photo`：保留的基础照片识别接口

服务端只公开前端运行所需文件；`.env`、服务端源码和说明文档不会通过静态服务暴露。接口带有同源检查、速率限制、请求大小限制、图片格式校验和上游超时。

## 检查与测试

```bash
npm run check
npm test
```

测试覆盖静态文件白名单、跨来源请求拒绝、AI 状态失败关闭、低置信度食物过滤，以及档案和图片载荷边界。

## 文件说明

- `index.html`：页面结构
- `styles.css`：视觉样式

- `tests/server.test.js`：安全和归一化回归测试
