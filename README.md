# 慧食·长辈膳食助手

面向长辈及家人的膳食记录与饭前提醒 Web 应用，支持手机号账号、短信验证、密码找回、文字、照片和语音输入。

- 在线试用：[https://huishi123.cn](https://huishi123.cn)
- 应用源码：[`惠食/慧食-长辈膳食助手-可分享版-20260709/慧食`](惠食/慧食-长辈膳食助手-可分享版-20260709/慧食)
- 运行与配置说明：[`README.md`](惠食/慧食-长辈膳食助手-可分享版-20260709/慧食/README.md)

真实服务密钥只能保存在未提交的 `.env` 文件或服务器环境变量中，不要写入前端代码或提交到 GitHub。

生产启用注册前，还需要配置真实短信服务商；手机号实名认证另需运营商二/三要素核验服务商。具体安全设计和 Webhook 协议见应用目录中的 `README.md`。
